# 手机业务补齐清单

授权范围：补齐现有业务逻辑，保持数据库结构、权限与库存算法不变。只使用本地数据库。

实施：复用电脑业务字段、校验、请求流程；手机独立 Vue + Vant 控件呈现卡片、弹出选择器及全屏编辑。不依赖 Element Plus 或旧模板。

已接入本地版本：
- 项目/订单/付款的完整操作、关联及打印
- 供应商/付款单位的新增编辑删除、联系人同步、对账
- 发票筛选/上传/OCR/编辑/票面/付款关联
- 材料看板/计划/入库/库存/出库/记录/批量/导入
- 苗圃看板/库存/入出库/出库单/流水/日志/基础设置
- 系统入口与权限、个人资料
- 卡片分页、选择器类型保真、多选、未保存保护、登录过期、写入锁

限制：真实云 OCR、云存储、备份、邮件与实体手机系统打印未验证，不能用模拟代替。

## 验证结果（2026-09-25）

- 手机端 112 项测试通过，电脑端 108 项测试通过，后端 48 项隔离数据库测试通过。
- 两端 TypeScript 检查及生产构建通过；手机构建不包含 Element Plus、Layui 或旧模板。
- 实际浏览器检查 28 个模块页面，390px 下无整页横向溢出；全部应用入口另检查360/430px。
- 实际点选字典卡片后，明细正确显示；供应商新增表单字段和必填标记可见；关联选择器保留数字ID，多选发票保留全部ID。
- 浏览器检查只读取现有本地记录，没有在实际业务数据库中创建/删除数据。新增、编辑、入出库等写入由隔离后端测试及前端接口流程测试覆盖，未宣称每个页面都经过实体手机端到端写入测试。
- 列表筛选默认折叠，卡片可自选显示字段；编辑/详情返回保留缓存列表状态与滚动位置。
- 表单网络失败保留当前输入；写入不自动重试；账号在其他页面变化时阻止旧表单提交。
- 共享字段/金额/库存校验位于 frontend-shared/business；业务请求仍沿用现有 Flask API。
- 苗圃基础设置沿用既有浏览器本地存储机制，不会自动同步到另一台设备。
- 入口 /m/#/apps。生产环境未连接、未发布、数据库结构未修改。
