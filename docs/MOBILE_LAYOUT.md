# 新版后台手机适配

新版 `/pc/` 和开发入口使用同一套响应式页面，独立手机端 `/m/` 继续可用。

- 小于 900px：侧栏改为抽屉菜单，支持关闭按钮、遮罩和 Escape；切回电脑尺寸清除遮罩状态。隐藏导航及打开菜单时的背景不接收键盘焦点。
- 小于等于 600px：筛选与录入表单单列排列，字段标签置于上方，输入框字体 16px，主要控件触控高度至少 44px。
- 宽表格在自身区域横向滑动；手机端取消固定操作列，滑到右侧即可查看操作。
- 弹窗限定在当前屏幕高度内，内容单独滚动，底部操作按钮保留。日期选择器、文件上传、长文字、详情字段、底部安全区域均做了适配。
- 响应式规则集中在 `frontend-desktop/src/responsive.css`，打印样式继续独立处理。

## 验证

- `frontend-desktop`：`npm test`，18 个文件、114 项测试通过；新增手机菜单 Escape、尺寸切换和焦点隔离状态回归测试。
- `npm run build`：通过。现有主包仍有大于 500kB 的体积提示。
- Chromium 浏览器模拟 320、390、768、1440px：概览、项目列表/新增/详情、订单、付款、发票、材料库存、苗圃库存、用户、个人资料共 44 组页面检查通过，页面主体无横向溢出。
- 320px 交互：菜单开关与尺寸切换、表格滑动后打开编辑、弹窗按钮、日期选择器通过。
- 浏览器业务检查使用请求拦截提供的模拟数据，未向真实业务库提交数据。测试脚本、结果和截图在 `output/playwright/`。

本次验证使用桌面 Chromium 模拟屏幕尺寸，尚未进行 iOS / Android 真机和软键盘测试。已更新本地构建，未发布公网。当前本地服务只监听 127.0.0.1，手机直接访问还需要配置局域网或正式部署地址。
