# 项目结构与清理记录

## 运行链路

`.flaskenv` → `pear_admin.create_app()` → `configs.py` → 扩展初始化 → `/api/v1` API 注册 → 页面路由注册。

| 模块 | 职责 |
| --- | --- |
| pear_admin/apis | 系统权限、项目、供应商、订单、付款、材料、苗圃、仪表盘、备份、门户 |
| pear_admin/orms | 业务实体、关联关系及 JSON 序列化 |
| pear_admin/views | HTML 页面路由 |
| pear_admin/extensions | 数据库、JWT、CLI、OSS、备份定时任务 |
| pear_admin/ocr_utils.py | 百度 OCR 接口与发票解析 |
| templates / static | 页面、Pear/Layui 静态资源、样式、模板文件 |
| data / migrations | 系统配置种子和正式数据库迁移 |
| scripts / nginx / 根目录部署脚本 | 运维及部署入口 |
