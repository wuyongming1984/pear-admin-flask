# 全站视觉统一（2026-09-25）

## 范围

- 旧版 `/`、`/legacy/`：50 个页面模板（含两个概览复用入口）接入公共视觉样式；为 19 个缺少标题区的业务页面增加标题及说明。
- 新电脑端 `/pc/`：统一导航、标签页、PageHeader、筛选区、表格、表单、弹窗、附件、统计卡片、登录和状态页面。
- 手机端 `/m/`：统一主色、卡片、表单、搜索、详情、空状态与底部导航，提高辅助文字的清晰度。
- 打印单和发票票面仅加载屏幕展示样式，保留已有字段和打印规则；新增业务标题在打印时隐藏。

## 实现

- `static/admin/css/ui-tokens.css`：三端共用的颜色、字体、圆角和阴影变量，由两个 Vite 工程各自打包。
- `templates/shared/presentation.html`、`static/admin/css/ui-polish.css`：旧版公共入口与样式。
- `frontend-desktop/src/polish.css`、`frontend/src/polish.css`：电脑和手机的组件样式。
- 核心业务、材料、苗圃、系统及个人资料统一使用现有 `PageHeader` 组件。
- 本次不修改数据库、API、权限、金额算法和单据处理流程；新旧入口继续并行。

- Codex 浏览器检查新版核心业务列表、项目新增、系统角色弹窗、材料及苗圃页面；检查旧版部门、付款和发票页面；检查手机首页、列表、项目新增和个人页面。
